## Вопросы

1.  Что такое Доменное событие (Domain Event) в контексте DDD?
    *   **A)** Событие пользовательского интерфейса, такое как клик кнопки.
    *   **B)** Событие, которое произошло в предметной области и представляет собой факт, имеющий значение для других частей системы.
    *   **C)** Системное событие, такое как ошибка базы данных.
    *   **D)** Событие интеграции с внешними системами.

2.  Когда следует публиковать Доменное событие?
    *   **A)** Только при создании новых Сущностей.
    *   **B)** Только при удалении Сущностей.
    *   **C)** Когда в предметной области происходит что-то важное, что может заинтересовать другие части системы.
    *   **D)** Только при изменении состояния Агрегата.

3.  Какой из следующих принципов является ключевым для Доменных событий?
    *   **A)** События должны содержать максимально подробную информацию о состоянии системы.
    *   **B)** События должны быть неизменяемыми (immutable) и представлять факты, которые уже произошли.
    *   **C)** События должны содержать логику обработки.
    *   **D)** События должны быть синхронными.

4.  Что такое Обработчик событий (Event Handler) в контексте Доменных событий?
    *   **A)** Компонент, который создает события.
    *   **B)** Компонент, который обрабатывает события и выполняет соответствующие действия.
    *   **C)** Компонент, который валидирует события.
    *   **D)** Компонент, который сохраняет события в базе данных.

5.  Какой паттерн часто используется для обработки Доменных событий?
    *   **A)** Паттерн Observer (Наблюдатель).
    *   **B)** Паттерн Singleton (Одиночка).
    *   **C)** Паттерн Factory (Фабрика).
    *   **D)** Паттерн Strategy (Стратегия).

    *   **C)** Увеличение производительности системы.
    *   **D)** Улучшение масштабируемости.

7.  Как Доменные события помогают в реализации Event Sourcing?
    *   **A)** Они автоматически сохраняются в базе данных.

    *   **C)** Они обеспечивают синхронизацию между сервисами.
    *   **D)** Они упрощают отладку.

8.  Что такое "Event Store" в контексте Доменных событий?
    *   **A)** База данных для хранения всех Доменных событий.

    *   **C)** Интерфейс для обработки событий.
    *   **D)** Система логирования событий.

    *   **A)** Синхронная обработка всех событий.

    *   **D)** Игнорирование событий в микросервисах.
